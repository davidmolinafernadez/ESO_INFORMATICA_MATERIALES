# Inteligencia artificial · Uso responsable

La IA puede ayudar a explorar ideas, aclarar conceptos, revisar un borrador o detectar posibles errores. No sustituye el aprendizaje, la comprobación ni la autoría personal.

## Protocolo de uso

1. **Define la tarea:** explica qué necesitas y qué sabes ya.
2. **Protege los datos:** no introduzcas nombres, imágenes, documentos privados, contraseñas ni información personal.
3. **Pide un resultado comprobable:** solicita pasos, ejemplos o criterios, no solo una respuesta final.
4. **Verifica:** contrasta hechos, cálculos, código, enlaces y citas con fuentes fiables.
5. **Transforma:** comprende, corrige y adapta el resultado con tus propias decisiones.
6. **Declara el uso:** indica qué herramienta utilizaste, para qué y qué cambios realizaste.

## Semáforo de decisiones

| Situación | Decisión |
|---|---|
| Pedir ideas o una explicación alternativa | :material-circle: Permitido si compruebas y reelaboras |
| Revisar ortografía o buscar fallos en un código propio | :material-circle: Permitido, conservando evidencias |
| Introducir datos personales o documentos privados | :material-close-circle: No permitido |
| Entregar una respuesta generada como si fuera propia | :material-close-circle: No permitido |
| Utilizar una cita o enlace sin verificar que existe | :material-close-circle: No permitido |

## Declaración breve para una entrega

> He utilizado __________ para __________. Comprobé el resultado mediante __________. Modifiqué o descarté __________ porque __________.

!!! warning "La IA puede inventar"
    Una respuesta segura y convincente también puede ser falsa, incompleta o sesgada. La responsabilidad sobre lo entregado sigue siendo de quien firma el trabajo.
