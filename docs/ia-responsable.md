# Uso ético y responsable de la IA

La IA se enseña porque el alumnado necesita criterios para utilizarla con control. Nunca se introducen datos personales, contraseñas ni documentos internos. Toda salida se considera un borrador: se contrasta, se modifica y se declara su uso.

## Declaración para las entregas

- Herramienta utilizada.
- Finalidad concreta.
- Partes empleadas.
- Cambios realizados por el alumno.
- Fuentes o pruebas usadas para verificar.

El alumno debe poder explicar y defender todo lo que entrega.
