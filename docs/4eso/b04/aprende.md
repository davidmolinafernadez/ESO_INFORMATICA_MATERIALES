# Aprende · Productividad, datos y decisiones

## 1. Modelo de datos

Una tabla limpia utiliza una fila por registro, una columna por variable, tipos coherentes, identificadores y un diccionario de datos.

## 2. Calidad

Completitud, validez, coherencia, unicidad y actualidad deben revisarse. Corregir no significa inventar valores ausentes.

## 3. Cálculo reproducible

Referencias absolutas y relativas, funciones condicionales, búsquedas, filtros y tablas dinámicas permiten automatizar el análisis.

## 4. Visualización honesta

Escalas, ejes, agregaciones y selección de periodos pueden distorsionar. Un gráfico debe mostrar contexto, fuente y limitaciones.

## 5. Protección

Minimización, anonimización, control de acceso y tiempo de conservación reducen la exposición de datos personales.

!!! tip "Método de trabajo"
    Conserva evidencias de tus decisiones y pruebas. Si algo falla, cambia una sola variable cada vez y anota el resultado.

!!! warning "Uso responsable"
    No utilices datos personales reales, contenido sin licencia ni acciones que puedan dañar equipos, cuentas o personas. Ante una duda de seguridad, detente y consulta.
