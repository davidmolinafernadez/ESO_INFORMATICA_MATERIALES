# Aprende · Desarrollo web y programación

## 1. Del problema a requisitos

Identifica usuarios, necesidad, alcance, datos de entrada, resultados, restricciones y criterios de aceptación antes de programar.

## 2. Modelo y diseño

Separa estructura HTML, presentación CSS y comportamiento JavaScript. Usa nombres claros, funciones pequeñas y una organización coherente.

## 3. Datos y lógica

Variables, colecciones, condiciones, bucles, funciones, eventos y almacenamiento local permiten construir aplicaciones interactivas.

## 4. Validación y seguridad

Valida entradas, limita datos recogidos, no incrustes secretos y trata el contenido como no confiable. La interfaz debe explicar errores sin culpar al usuario.

## 5. Pruebas e iteración

Casos normales, extremos y erróneos; registro de incidencias; control de versiones; revisión con usuarios y mejora basada en evidencias.

!!! tip "Método de trabajo"
    Conserva evidencias de tus decisiones y pruebas. Si algo falla, cambia una sola variable cada vez y anota el resultado.

!!! warning "Uso responsable"
    No utilices datos personales reales, contenido sin licencia ni acciones que puedan dañar equipos, cuentas o personas. Ante una duda de seguridad, detente y consulta.
