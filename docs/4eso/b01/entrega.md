# Entrega y evaluación · 4.º ESO

## Auditoría previa

- [ ] La estructura responde a las fases reales del proyecto.
- [ ] Los nombres permiten identificar contenido, versión y fecha.
- [ ] Cada permiso está justificado por una necesidad.
- [ ] El protocolo diferencia sincronización, historial y copia de seguridad.
- [ ] La incidencia tiene un procedimiento seguro y reproducible.
- [ ] Las fuentes se evalúan con cuatro criterios explícitos.
- [ ] La guía permite incorporarse sin ayuda oral.
- [ ] No hay datos personales innecesarios ni enlaces abiertos sin justificación.

## Rúbrica resumida

| Aspecto | Peso | Evidencia de calidad |
|---|---:|---|
| Arquitectura documental | 20 % | Estructura clara, proporcionada y mantenible |
| Versionado y recuperación | 20 % | Normas precisas y respuesta sólida a la incidencia |
| Permisos y seguridad | 20 % | Matriz coherente basada en mínimo privilegio |
| Fuentes y ciudadanía | 20 % | Análisis argumentado y decálogo aplicable |
| Documentación | 15 % | Guía autónoma, clara y visualmente cuidada |
| Entrega | 5 % | Enlaces comprobados, formato correcto y puntualidad |

!!! success "Nivel excelente"
    No solo presentas una solución: demuestras que la has probado, anticipas fallos y justificas por qué puede mantenerse en el tiempo.
