# Entrega y evaluación · Inteligencia artificial, agentes y automatización

La unidad se evalúa mediante evidencias prácticas. **No se realizará examen tradicional.**

| Evidencia | Peso |
|---|---:|
| Cuatro actividades | 60 % |
| Proyecto de unidad | 40 % |

## Rúbrica común

| Criterio | Avanzado | Adecuado | En proceso | Inicial |
|---|---|---|---|---|
| Saber y aplicar | Explica, aplica y relaciona | Aplica lo esencial | Necesita ayuda frecuente | No demuestra lo esencial |
| Producto | Completo, funcional y cuidado | Cumple con fallos menores | Incompleto o poco comprobado | No funciona o no se entrega |
| Proceso | Planifica, prueba y mejora con evidencias | Muestra proceso suficiente | Evidencias parciales | No muestra proceso |
| Responsabilidad | Protege datos, acredita y declara IA | Cumple requisitos básicos | Necesita correcciones | Presenta riesgos o copia |

## Lista de Aules

- [ ] El archivo tiene el nombre y formato solicitados.
- [ ] El enlace funciona con el permiso indicado.
- [ ] He abierto el producto final y comprobado su funcionamiento.
- [ ] He citado información, imágenes, código y otros recursos.
- [ ] He declarado el uso de IA o indicado que no la he utilizado.
- [ ] La tarea aparece como enviada y conservo una copia.
