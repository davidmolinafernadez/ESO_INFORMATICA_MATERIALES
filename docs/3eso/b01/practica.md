# Práctica · Mi mochila digital

## El reto

Crearás una estructura de trabajo que puedas mantener durante todo el curso y prepararás la primera página de tu portfolio.

## Tareas

1. Crea una carpeta llamada `3ESO_INFORMATICA`.
2. Dentro, crea `01_Trabajos`, `02_Recursos`, `03_Entregados` y `04_Portfolio`.
3. Dentro de `01_Trabajos`, crea una carpeta para cada bloque del curso.
4. Crea el documento `3ESO_B01_Portfolio_Nombre_v01`.
5. Incluye una presentación de cuatro líneas, tres objetivos personales y una tabla con las herramientas digitales que ya sabes utilizar.
6. Localiza dos fuentes fiables sobre huella digital. Anota título, entidad responsable, fecha, enlace y una razón para confiar en cada una.
7. Redacta cinco reglas personales de ciudadanía digital.
8. Comparte el documento con el permiso indicado por el profesor y comprueba cómo lo ve otra persona.

## Qué entregarás

- una captura donde se vea el árbol de carpetas;
- el enlace al portfolio con el permiso solicitado;
- las dos fuentes justificadas;
- tus cinco reglas de ciudadanía digital.

!!! danger "Protege tu privacidad"
    No incluyas dirección, teléfono, contraseñas, horarios personales ni otros datos que no sean necesarios para la actividad.
