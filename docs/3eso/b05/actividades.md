# Actividades · Creación multimedia

Las actividades se realizan durante las sesiones y se entregan en **Aules**. Conserva el archivo editable y entrega el formato indicado.

## Actividad 1

**Tarea.** Analizar una pieza breve: audiencia, mensaje, encuadre, sonido y licencia.

**Evidencia.** Un archivo o enlace con el nombre `3ESO_B05_A1_Nombre_v01`.

**Antes de entregar.** Comprueba contenido, funcionamiento, fuentes, datos personales y permiso del enlace.

**Valor.** 15 % de la unidad.

## Actividad 2
