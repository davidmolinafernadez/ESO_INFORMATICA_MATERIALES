## 1. Problemas y algoritmos

Un algoritmo es una secuencia finita y ordenada para resolver un problema. Antes de programar se identifican entradas, resultado esperado, restricciones y casos de prueba. Dividir el reto en partes reduce la complejidad.

## 2. Secuencia, eventos y estado

La secuencia determina el orden. Los eventos ponen en marcha acciones y las variables guardan un estado que puede cambiar. Nombrar variables por su significado facilita entender y revisar el programa.

## 3. Condiciones

Una condición permite elegir entre caminos según una expresión verdadera o falsa. Los operadores comparan valores y combinan decisiones. Conviene probar el límite, el caso normal y un dato no válido.

## 4. Repeticiones

Los bucles repiten instrucciones un número de veces o mientras se cumple una condición. Se evitan repeticiones infinitas comprobando qué cambia en cada vuelta. Un bloque propio puede reutilizar una tarea frecuente.

## 5. Depuración

Depurar consiste en localizar por qué el resultado real difiere del esperado. Se reproduce el error, se reduce el caso, se observa el estado y se cambia una causa cada vez. La tabla de pruebas convierte impresiones en evidencias.

## 6. HTML y CSS

HTML describe la estructura y el significado: títulos, párrafos, listas, enlaces e imágenes. CSS controla presentación. Separarlos mejora mantenimiento. Una página válida conserva jerarquía de encabezados y textos alternativos útiles.

## 7. Publicación responsable

Antes de publicar se revisan enlaces, navegación, lectura móvil, contraste, fuentes y datos personales. Una web pública no debe revelar información privada. Los créditos explican recursos ajenos y el uso de IA, si lo hubo.
