# Aprende · Programación y web

## 1. Pensamiento computacional

Descomponer, reconocer patrones, abstraer y diseñar algoritmos permite abordar problemas complejos paso a paso.

## 2. Algoritmos

Secuencia, decisión y repetición son estructuras básicas. Un algoritmo debe ser preciso, finito y comprobable.

## 3. HTML

HTML describe la estructura: títulos, párrafos, listas, enlaces, imágenes y secciones. La semántica mejora accesibilidad y mantenimiento.

## 4. CSS

CSS controla presentación, colores, espaciado y distribución. Separa contenido y apariencia.

## 5. Programar y probar

Variables, condiciones, bucles y eventos permiten interacción. Prueba casos normales, límites y errores; corrige una causa cada vez.

!!! tip "Método de trabajo"
    Conserva evidencias de tus decisiones y pruebas. Si algo falla, cambia una sola variable cada vez y anota el resultado.

!!! warning "Uso responsable"
    No utilices datos personales reales, contenido sin licencia ni acciones que puedan dañar equipos, cuentas o personas. Ante una duda de seguridad, detente y consulta.
