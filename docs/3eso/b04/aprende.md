## 1. Documentos con estructura

Título, encabezados, párrafos y listas expresan la jerarquía del contenido. Los estilos permiten cambiar el diseño sin perder estructura y facilitan la accesibilidad. Espacios y saltos repetidos no sustituyen a márgenes, alineación y saltos de página.

## 2. Tablas e imágenes

Una tabla compara datos cuando filas y columnas tienen encabezados claros. Las imágenes necesitan tamaño legible, proporción correcta, procedencia y texto alternativo cuando aporta información. Cada elemento debe cumplir una función comunicativa.

## 3. Datos y celdas

Una hoja de cálculo organiza datos en filas y columnas. Cada celda puede contener texto, número, fecha o fórmula. Separar datos originales, cálculos y resultados reduce errores y permite revisar el proceso.

## 4. Fórmulas y referencias

Una fórmula empieza con igual y combina valores, operadores, funciones y referencias. SUMA, PROMEDIO, MÍNIMO, MÁXIMO y CONTAR resuelven preguntas distintas. Copiar una fórmula cambia referencias relativas, por lo que se comprueba el resultado.

## 5. Calidad del dato

Un dato puede estar ausente, duplicado, fuera de rango o escrito con un formato incoherente. Limpiar significa detectar y documentar estas situaciones, no modificar números para que apoyen una conclusión. La fuente y la fecha forman parte del conjunto de datos.

## 6. Gráficos

Barras comparan categorías, líneas muestran evolución y sectores representan partes de un total con pocas categorías. Un gráfico necesita título, unidades y escala comprensible. El tipo se elige según la pregunta, no por decoración.

## 7. Interpretación responsable

La media puede ocultar diferencias y un eje recortado exagerar cambios. Se distingue observación de interpretación y se reconocen límites del conjunto. Un informe responsable permite rastrear cada resultado hasta los datos originales.
