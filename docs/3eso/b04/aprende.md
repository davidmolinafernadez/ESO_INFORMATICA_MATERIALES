# Aprende · Ofimática y tratamiento de datos

## 1. Documentos con estructura

Título, subtítulos, estilos, listas, tablas y pies permiten leer y actualizar mejor. El formato debe servir al mensaje, no decorarlo.

## 2. Datos tabulares

Cada fila representa un registro y cada columna una variable. Los encabezados deben ser claros, las unidades coherentes y las celdas no deben mezclar varios datos.

## 3. Fórmulas

Una fórmula empieza con igual y usa referencias. SUMA, PROMEDIO, MÍNIMO, MÁXIMO y CONTAR permiten obtener resultados reproducibles.

## 4. Gráficos

Elige barras para comparar, líneas para evolución y sectores solo para pocas partes de un total. Incluye título, unidades y fuente.

## 5. Privacidad y accesibilidad

Recoge únicamente datos necesarios, anonimiza cuando proceda y utiliza contraste, texto alternativo y estructuras legibles.

!!! tip "Método de trabajo"
    Conserva evidencias de tus decisiones y pruebas. Si algo falla, cambia una sola variable cada vez y anota el resultado.

!!! warning "Uso responsable"
    No utilices datos personales reales, contenido sin licencia ni acciones que puedan dañar equipos, cuentas o personas. Ante una duda de seguridad, detente y consulta.
