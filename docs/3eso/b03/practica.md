# Práctica · Redes, ciberseguridad y privacidad

## El reto

Dibuja el mapa de una red doméstica ficticia, realiza un análisis de ocho mensajes simulados y crea una guía de respuesta ante phishing, pérdida de dispositivo y cuenta comprometida.

## Fases recomendadas

1. **Comprender:** reformula el problema y anota las restricciones.
2. **Planificar:** divide el trabajo, prepara carpetas y define el resultado esperado.
3. **Crear:** construye una primera versión pequeña y comprobable.
4. **Probar:** registra errores, opiniones y evidencias.
5. **Mejorar:** aplica los cambios prioritarios y justifícalos.
6. **Entregar:** comprueba nombres, permisos, enlaces, fuentes y formato.

## Entregables

- Mapa de red con dispositivos y conexiones.
- Clasificación razonada de ocho mensajes.
- Plan personal de seguridad en diez puntos.
- Protocolo de respuesta para tres incidentes.

!!! info "Trabajo auténtico"
    El resultado debe poder entenderse y utilizarse sin una explicación privada del equipo. Incluye instrucciones suficientes para otra persona.
