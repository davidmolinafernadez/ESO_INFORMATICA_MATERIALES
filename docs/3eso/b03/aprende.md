## 1. Qué es una red

Una red conecta dispositivos para intercambiar datos y compartir servicios. En una red doméstica intervienen clientes, punto de acceso, router y proveedor. Internet conecta muchas redes, mientras que la Web es uno de los servicios que funciona sobre Internet.

## 2. Direcciones y nombres

Una dirección IP identifica una interfaz en una red. El router encamina paquetes entre redes y DNS traduce nombres fáciles de recordar a direcciones. Estos elementos cooperan, pero no cumplen la misma función.

## 3. Wi-Fi

La cobertura depende de distancia, obstáculos, interferencias y ubicación del punto de acceso. Una red segura usa cifrado actual, contraseña robusta y firmware actualizado. La red de invitados separa dispositivos que no necesitan acceso interno.

## 4. Amenazas y engaño

Phishing, malware, suplantación e ingeniería social buscan obtener datos o provocar una acción. Urgencia, miedo, remitentes parecidos y enlaces inesperados son señales. Ninguna señal aislada demuestra el fraude: se verifica por un canal independiente.

## 5. Autenticación y actualizaciones

Las contraseñas deben ser largas y únicas. Un gestor facilita no reutilizarlas y el doble factor añade una comprobación. Las actualizaciones corrigen fallos conocidos; posponerlas indefinidamente mantiene vulnerabilidades abiertas.

## 6. Copias y privacidad

Una copia útil se puede recuperar y no depende del mismo fallo que el original. La regla 3-2-1 orienta: varias copias, medios distintos y una fuera del dispositivo principal. Los datos personales solo se recogen y comparten cuando son necesarios.

## 7. Respuesta a incidentes

Ante un mensaje sospechoso: detenerse, no interactuar, conservar evidencias sin difundir datos, avisar y verificar. Si hubo acceso, se cambian credenciales desde un equipo seguro, se cierran sesiones y se siguen las indicaciones del centro o servicio.
